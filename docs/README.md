# Trash Pickup Rules Documentation

This directory contains comprehensive research on trash pickup schedules, zones, and GIS data availability for TrashAlert pilot cities.

## Contents

### Summary Document
- **[TRASH_RULES_SUMMARY.md](TRASH_RULES_SUMMARY.md)** - Executive summary of all findings, implementation priorities, and next steps

### City-Specific Documentation

1. **[trash_rules_el_centro.md](trash_rules_el_centro.md)** - El Centro
   - Provider: CR&R Environmental Services
   - Zone system: Interactive map available
   - GIS data: Potentially available

2. **[trash_rules_brawley.md](trash_rules_brawley.md)** - Brawley
   - Provider: Republic Services
   - Zone system: Unknown, must contact provider
   - GIS data: Unknown

3. **[trash_rules_imperial.md](trash_rules_imperial.md)** - Imperial
   - Provider: Republic Services
   - Zone system: **None - citywide Wednesday collection**
   - GIS data: Not needed
   - **Status**: Ready to implement

4. **[trash_rules_calexico.md](trash_rules_calexico.md)** - Calexico
   - Provider: Republic Services
   - Zone system: Monday-Saturday collection (6 zones likely)
   - GIS data: Unknown

5. **[trash_rules_holtville.md](trash_rules_holtville.md)** - Holtville
   - Provider: CR&R Environmental Services
   - Zone system: Must contact CR&R for zone assignment
   - GIS data: Unknown

6. **[trash_rules_san_diego.md](trash_rules_san_diego.md)** - San Diego
   - Provider: City Environmental Services Department
   - Zone system: Interactive lookup tool available
   - GIS data: Potentially available via SanGIS

This research was conducted through:
- Web searches for official city websites
- Service provider websites (CR&R, Republic Services)
- GIS data portals (SanGIS, Imperial County GIS)
- Municipal public works departments
- Environmental services websites
