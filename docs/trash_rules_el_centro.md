## Pickup Zone System

### Interactive Map Available
El Centro provides an **Interactive Street Sweeping and Trash Pick-up Days Map** that allows residents to:
- Find their specific trash pickup day by address
- View street sweeping schedules
- Access via QR code or city website

**Map Access**: https://www.cityofelcentro.org/1316/Street-Sweeping

### How Zones Are Defined
- Zones appear to be geographically mapped by street/address
- Residents can look up their specific day using the interactive map
- No public documentation of zone boundaries found

## Collection Schedule

### Service Details
- **Container Placement**: No later than 6:00 AM on collection day
- **Container Removal**: Within 12 hours after service
- **Cart Types**: Three-cart automated system (trash, recycling, green waste)

### Holiday Schedule
- If holiday falls on Saturday/Sunday: Normal collection day, no delays
- If holiday falls on weekday: Collection for remainder of week postponed by one day
- Observed Holidays: New Year's Day, Memorial Day, Independence Day, Labor Day, Thanksgiving, Christmas
