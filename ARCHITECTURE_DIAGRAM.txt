CONSENSUS ALGORITHM FLOW
=========================

┌─────────────────────────────────────────────────────────────────────┐
│                     CONSENSUS CALCULATION                            │
│                                                                       │
│  Input: All crowd_reports for address_id                             │
│                                                                       │
│  For each service (trash, recycling, green_waste):                   │
│                                                                       │
│    1. Extract all reported schedules                                 │
│       ["MON,THU", "MON,THU", "MON,FRI", "MON,THU"]                  │
│                                                                       │
│    2. Count frequency of each unique schedule                        │
│       "MON,THU": 3 occurrences                                       │
│       "MON,FRI": 1 occurrence                                        │
│                                                                       │
│    3. Select most common schedule as consensus                       │
│       consensus_days = ["MONDAY", "THURSDAY"]                        │
│                                                                       │
│    4. Calculate agreement ratio                                      │
│       agreement_ratio = 3/4 = 0.75 (75%)                            │
│                                                                       │
│    5. Store metadata                                                 │
│       total_reports = 4                                              │
│       agreement_count = 3                                            │
│                                                                       │
│  Verification Check:                                                 │
│    IF total_reports >= 3 AND agreement_ratio >= 0.67:               │
│       is_verified = TRUE                                             │
│    ELSE:                                                             │
│       is_verified = FALSE                                            │
│                                                                       │
│  Output: Updated crowd_consensus record                              │
└─────────────────────────────────────────────────────────────────────┘


MULTI-SOURCE PRIORITY ENGINE
=============================

┌─────────────────────────────────────────────────────────────────────┐
│                        LOOKUP PRIORITY LOGIC                         │
│                                                                       │
│  1. Check for VERIFIED CROWD DATA                                    │
│     Query: crowd_consensus WHERE is_verified = TRUE                  │
│     ├─ FOUND ─→ Return (Source: CROWD_VERIFIED, Confidence: HIGH)   │
│     └─ NOT FOUND ─→ Continue to step 2                              │
│                                                                       │
│  2. Check for OFFICIAL SCHEDULE                                      │
│     Query: schedules WHERE effective_date <= today                   │
│               AND (end_date IS NULL OR end_date > today)            │
│     ├─ FOUND ─→ Return (Source: OFFICIAL, Confidence: MEDIUM)       │
│     └─ NOT FOUND ─→ Continue to step 3                              │
│                                                                       │
│  3. Check for UNVERIFIED CROWD DATA                                  │
│     Query: crowd_consensus (any record)                              │
│     ├─ FOUND ─→ Return (Source: CROWD_UNVERIFIED,                   │
│     │           Confidence: LOW, Warning: "Not yet verified")        │
│     └─ NOT FOUND ─→ Continue to step 4                              │
│                                                                       │
│  4. NO DATA AVAILABLE                                                │
│     Return: (Source: UNKNOWN, Confidence: NONE,                      │
│              Message: "Be the first to report!")                     │
└─────────────────────────────────────────────────────────────────────┘
